## 定義: 完了の定義（DoD）

- コードレビュー完了
- 単体テスト記述済み（OCRパーサーは必須）
- 医療アドバイス・薬事法違反コンテンツが含まれていないことを確認
- OCRエラー時のユーザーフィードバックが実装されていること

## リスク・前提条件

| リスク | 対策 |
|--------|------|
| 日本語OCR精度（医療用語・数値の誤読） | 確認UIで必ず人間がレビューする設計で対処 |
| 医療機関ごとの用紙フォーマット多様性 | 動的Key-Value型で吸収。MVP後にフォーマットテンプレート機能を検討 |
| 薬事法・医療機器規制 | データ表示のみ（診断・アドバイス機能なし）を設計レベルで担保 |
| Firebase依存 | Auth のみ使用。DB はローカルRoomで独立性を確保 |
