## 3. ストア説明文（案）

### アプリ名
`健康診断マネージャー`

### 短い説明文（80字以内）
`健康診断の結果をOCRで読み取り、経年変化をグラフで管理できるアプリです。`

### 詳細説明文（案）

```
健康診断マネージャーは、毎年の健康診断結果を手軽に記録・管理できるAndroidアプリです。

【主な機能】
・カメラで健康診断の結果用紙を撮影するだけでデータを記録
・OCR読み取り結果を画面で確認・手動修正可能
・血圧・血糖値・コレステロールなど検査項目ごとの経年変化グラフ
・基準値を登録して、外れた項目を一目で確認
・Googleアカウントでデータを安全に管理

【プライバシー・セキュリティ】
・健康診断データは端末内にのみ保存されます
・クラウドへの健康データの送信は行いません

【免責事項】
本アプリは健康診断結果の記録・閲覧を補助するツールです。
医療診断・治療方針の提示を行うものではありません。
健康上の不安がある場合は、医療機関にご相談ください。
```

## 6. 必要な Firebase 設定（本番リリース前）

1. Firebase Console → プロジェクト設定 → SHA 証明書フィンガープリントに **リリース用 SHA-1** を追加
2. `google-services.json` を再ダウンロードしてプロジェクトに反映
3. Firebase Auth → 承認済みドメインにアプリのリダイレクト URI を設定
